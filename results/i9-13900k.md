# reference numbers: i9-13900K, 64 GB DDR5-4800, no GPU

The machine the whole writeup is measured on. Gemma-4-26B-A4B, Q4_0, top-3 experts.

## single stream (latency)

| config | tok/s |
|---|---|
| plain Q4_0, no tricks | ~25 |
| + top-3 + MTP speculative decoding (lossless) | ~40 (37.7 careful, ~41 idle/turbo) |

Threads: flat across 8 / 16 / 24 (bandwidth-bound). Use 8.

## batched (throughput)

Aggregate generation tok/s (`S_TG`), sweeping parallel streams:

| batch | t=8 | t=24 |
|---|---|---|
| 1 | 28 | - |
| 4 | 69 | - |
| 8 | 81 | - |
| 16 | 93 | 114 |
| 32 | - | 124 |

Threads help here (compute-bound): batch 16 goes 93 -> 114 from 8 to 24 threads.

## bandwidth

STREAM-triad achievable: **64.5 GB/s** (84% of the 76.8 the DDR5-4800 spec implies). Single-stream decode
runs at ~78% of that 64.5, with repacking on.

## notes

tok/s drifts with turbo/thermal/load; the *shape* (threads flat for latency, threads helping throughput; the
byte-budget proportions) is what should reproduce. AVX2, no AVX-512 (the 13900K has it fused off).
